## 実行

Python 3.10以降を使用します。追加ライブラリは不要です。

```sh
cd experiment20
python -X utf8 mine_patterns.py graphs.json --output results/my-run.json
python -X utf8 test_miner.py
```

比較実験とレポートの再生成は、同じディレクトリで次を実行します。保存済みの評価結果を上書きします。

```sh
python -X utf8 evaluate.py
python -X utf8 write_report.py
```

## 検証範囲

原文20件・構造化グラフ・期待グループは、同じAI作成者が実験用に設計した仮想データです。機密ノウハウは含みません。原文からの自動抽出やBedrock呼び出しは実装・実行していません。

保存済みの実験では、意味関係1〜2個の連結断片から7種類の繰り返し構造を検出しました。部分構造とその上位構造が重複しているため、独立した7原理という意味ではありません。19テストには、独立した全順列判定との80組の比較を含みます。

この結果は構造化後の探索処理の動作確認です。抽出プロンプトの精度、実データでの精度、1,000件での速度、異分野への転用効果は未検証です。表現が一致しても、意味や適用条件の妥当性は別途確認する必要があります。
